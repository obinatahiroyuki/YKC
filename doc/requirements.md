# 要件定義書：横浜経営者倶楽部 (YKC) 会員向けアプリ

本ドキュメントは、「横浜経営者倶楽部」の会員向けアプリケーションの要件を定義したものです。発注者からのプロトタイプに基づく確定仕様を網羅しています。

## 1. システム構成・技術スタック
- **フロントエンド・バックエンド**: Next.js (App Router) + プレミアムVanilla CSS
- **データベース**: Turso (SQLite Edge Database) + Drizzle ORM
- **画像ストレージ**: Uploadthing または Cloudinary （※完全無料枠で運用）
- **ホスティング**: Vercel
- **アプリ配信**: PWA (ホーム画面に追加) 推奨とし、同一コードベースでiOS/Androidにリスクゼロで提供。
- **通知およびメール配信**: FCM (Web Push) ＋ メール配信(Resend)
- **認証基盤**: NextAuth / Auth.js（※招待制向けに Credentials 認証に限定）

## 2. ユーザーロール（権限設定）
本アプリはユーザー自身での新規登録フローを持たないクローズド仕様です。

1. **管理者 (Admin)**
   - ユーザーのアカウント作成・招待（ID/パスワード発行）
   - 「企業クローズアップ」のデータ登録・管理（※管理者のみ更新可能）
   - 掲示板等における不適切投稿の監視・ワンタップ削除インターフェース等の保有
2. **一般ユーザー (User)**
   - パスワードによるログイン、プロフィールの編集
   - 業種別等での会員検索、マッチング・非同期DM
   - 掲示板への書き込み（即時公開）、イベント申込み、退会申請

## 3. 機能要件

### 3.1 メンバー検索・マッチングと安全性
- **業種別検索**: 業種やタグに基づき会員を検索、プロフィール閲覧。
- **マッチング**: 相性サジェストや「いいね」による繋がりと、非同期の安全なメッセージ機能。
- **安全性**: 違反ユーザーのブロック・通報機能の常備。

### 3.2 掲示板機能（Bプラン：事後パトロール制）
- **掲示板**: ゴルフ・飲み会などの会員主催オフ会を投稿して交流できる機能。
- **運用仕様**: 投稿は即時に全会員へ公開（スピード重視）。不適切な内容が投稿された場合は、通報ボタンや管理者の監視により事後的に削除対応を行う仕様。

### 3.3 企業PR・連携・問合せ機能（コスト最適化）
- **企業クローズアップ**: 会員企業のPR情報やサービス。
- **動画仕様**: サーバー維持費を防ぐため「動画ファイルの直接アップロード」は不可とし、**「YouTubeまたはVimeoなどの外部サイト動画のURL埋め込み」に限定**して表示する。
- **問合せ・個別相談フォーム**: 営業支援や各種相談をアプリ内から直接申請できる専用フォームを実装。日程調整のやり取りを最小化するため、Zoomミーティングの「希望日程・時間帯」を**第一希望から第三希望まで入力できる仕様**とする。
- **外部導線**: 「飛山ブログ」等の外部サイトへブラウザ（新規タブ）で遷移させるリンクバナーの設置。

### 3.4 イベントと通知管理（ベルマーク）
- **イベント管理**: 事務局主催のイベント申込みと、「キャンセル待ち」のエントリーシステム。参加費決済は外部サイトへ誘導。
- **参加者リストの出力機能**: イベント当日の受付名簿作成などの事務負担を軽減するため、管理者は参加者一覧を「CSVデータ」としてワンクリックでダウンロードできる仕様とする。
- **通知センター（履歴管理）**: プッシュ通知の受信に加え、アプリ内のベルマークからデータベースに保存された「過去の通知一覧（未読/既読付き）」を確認できる機能。

## 4. 非機能要件
- **モバイルファースト・UX**: スマートフォン（Android/iOS共通）からストレスなくアプリとして利用できるUI設計。ダークネイビーとゴールドを基調とした高級感のあるデザイン。
- **ストア審査対策**: アプリストア申請を行う場合でも通るよう、通報処理、退会手続きを組み込む。
- **強力な情報漏洩対策（SEOブロック）**: 会員データやプロフィールの流出を絶対的に防ぐため、ログイン画面以外のすべてのページに対して、Googleなどの検索エンジンへの登録を強制拒否するメタタグ（`noindex, nofollow`）を厳密に設定する。
